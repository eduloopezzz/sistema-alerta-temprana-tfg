CÓMO LEER ESTE MAPA

El Modelo B predice la tasa del año t+1 a partir del valor del año t (lag-1) y las variables socioeconómicas. Su precisión es elevada porque la criminalidad provincial es fuertemente inercial: la mejor predicción del año siguiente es el valor actual. Por ello, este mapa funciona principalmente como sistema de alerta que identifica provincias con riesgo persistente, no como herramienta para evaluar el efecto de intervenciones puntuales. Para entender qué variables influyen estructuralmente en cada provincia, consulta la pestaña 02. Análisis Explicativo.

¿QUÉ FACTORES EXPLICAN LAS DIFERENCIAS?

Coeficientes within del Modelo A' con efectos fijos provinciales

El Modelo A' aísla el efecto causal de cada variable socioeconómica controlando por la heterogeneidad estructural de cada provincia mediante efectos fijos provinciales. Los coeficientes que se muestran a continuación representan el cambio en la tasa de criminalidad cuando, dentro de una misma provincia, varían las condiciones económicas a lo largo del tiempo. El test F de poolability rechaza categóricamente la hipótesis de que estos efectos sean innecesarios: F(51, 516) = 119,07; p < 0,001.

INTERPRETACIÓN PARA POLÍTICA PÚBLICA

Los coeficientes within del Modelo A' identifican el efecto causal de las variables socioeconómicas sobre la criminalidad dentro de una misma provincia a lo largo del tiempo. Las dos palancas accionables y estadísticamente significativas son el desempleo (efecto positivo: cada punto porcentual adicional de paro se asocia con +17,6 delitos por 100.000 habitantes) y la renta neta media (efecto negativo: cada 1.000 € adicionales se asocian con −69,3 delitos). Estas son las direcciones esperadas por la teoría de la elección racional (Becker, 1968): cuando el coste de oportunidad del delito sube, la criminalidad baja. Las magnitudes son moderadas, lo que indica que las medidas de política social son palancas válidas pero no instantáneas y requieren sostenerse en el tiempo para reducir la tasa estructural de cada provincia.

DIAGNÓSTICO Y RECOMENDACIONES POR PROVINCIA

Fichas accionables provinciales

Para cada provincia, el sistema cruza la predicción del Modelo B con los efectos within del Modelo A' para producir un diagnóstico cuantitativo y un conjunto de recomendaciones priorizadas. Las propuestas se inspiran en la literatura de prevención social proactiva (González-Álvarez et al., 2020; Martínez Garay, 2024).
